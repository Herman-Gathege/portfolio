Everyday Finds Store

A full-stack e-commerce platform that enables users to browse products, add items to their cart, and complete secure purchases while allowing administrators to manage products and track store performance.

Role Fullstack Developer

Problem

Many small online stores lack scalable systems that support product management, secure payments, and meaningful analytics for understanding store performance.

Solution

Everyday Finds delivers a modern e-commerce experience with product browsing, secure checkout, and an admin dashboard for managing inventory and monitoring store analytics.

Key Features

  • User authentication and authorization
  • Shopping cart and product management
  • Stripe payment integration
  • Cloudinary image hosting
  • Admin dashboard with sales analytics

Implementation

  • React frontend for dynamic user experience
  • Node.js and Express backend APIs
  • MongoDB database for flexible product data
  • Stripe used for payment processing
  • Optimized APIs for cart and product operations
