Graceful Impressions

A full-stack digital marketplace designed to connect Kenyan visual artists with global art enthusiasts, helping painters showcase their work, build audiences and increase potential art sales online.

Role Fullstack Developer

Type Art Marketplace Platform
Tools Supabase · Bootstrap · Figma

Problem

Many talented artists struggle to reach wider audiences and monetize their artwork because they lack accessible digital platforms to showcase their work and manage their artistic presence.

Solution

Graceful Impressions provides a digital platform where artists can create profiles, upload artwork, promote events and connect with art lovers globally through an accessible online gallery experience.

Key Features

  • Artist profile management
  • Artwork uploads and digital gallery
  • User registration and authentication
  • Event and exhibition management
  • Responsive cross-device browsing experience

Implementation

  • Frontend built with React for responsive UI
  • Flask REST APIs for backend services
  • PostgreSQL database hosted on Supabase
  • Secure authentication system for artists and users
  • Deployed using Render for full-stack hosting
