How I work

I started in full-stack application development and moved into SaaS and enterprise work: multi-tenant platforms, event-driven backends, financial workflows, AI integrations and process automation. Today I work across Python, React, PostgreSQL, Laravel and containerised Linux infrastructure.

I like problems with real operational constraints — statutory payroll deductions, rent reconciliation, provider failovers, approval chains in a public-sector organisation. My approach is to model the domain properly first, keep APIs modular, and make the system observable enough that problems can be found quickly.

I take ownership end to end: requirements analysis, architecture, database design, backend and frontend delivery, testing, deployment, monitoring and production troubleshooting.

Engineering

What I've built depth in

Multi-tenant architecture

Organisation-scoped data isolation, tenant-aware queries and role-based access control applied consistently from the API layer through frontend routes — used in AlphaOne and the SME management platform.

Event-driven & asynchronous processing

Redis and Celery workers that separate notification delivery, invoice transmission and heavy reporting from synchronous API requests, with retries and delivery tracking.

Provider abstraction

Pluggable communication and AI providers — email, SMS, SMTP, WhatsApp, Resend, and Claude via OpenRouter — so new providers can be added without touching core application logic.

Production infrastructure

Docker and Docker Compose stacks running PostgreSQL, Redis, Nginx or Caddy, backend workers and frontends on Ubuntu, with HTTPS, persistent volumes and automated PostgreSQL backups.

Observability & troubleshooting

Prometheus metrics, health endpoints, structured logging and request ID tracing — plus the practical debugging that comes with Docker networking, service health checks, reverse proxies and deployment synchronisation.

End-to-end ownership

Requirements analysis, system architecture, database design, API and frontend delivery, testing, deployment, technical SEO and monitoring — delivered with controlled Git branching and release workflows.
