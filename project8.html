AlphaOne Rental Management System

Multi-tenant rental property management platform for managing properties, tenants, leases, payments and rental operations across Kenya and East Africa.

Problem

Property owners and managers rely on fragmented systems or manual processes to track tenants, leases, rent payments and operational data, which creates inefficiencies and increases the risk of financial discrepancies.

Solution

AlphaOne provides a centralized multi-tenant platform that digitizes property, unit, tenant and lease management while automating monthly billing, payment recording, and financial reconciliation for landlords and property managers.

Key Features

  • Multi-tenant organization and role-based access
  • Property and unit management with occupancy tracking
  • Tenant onboarding and lease lifecycle management
  • Automated monthly charge generation and billing
  • Payment recording with M-Pesa, cash and bank support
  • Auto-settlement of pending and overdue charges
  • Financial dashboards with tenant balances and revenue summaries
  • Team management with role-based permissions
  • Audit logging and secure JWT authentication

Implementation

  • React frontend with feature-based architecture and Context API
  • FastAPI backend with SQLAlchemy and Alembic migrations
  • PostgreSQL database with multi-tenant data isolation
  • Redis for token handling and background task infrastructure
  • JWT authentication with access and refresh tokens
  • Role-based access control for landlord, manager, finance and tenant roles
  • Docker Compose orchestration for reproducible environments
  • Nginx reverse proxy for production frontend serving

Engineering Highlights

  • Docker-first development with one-command startup
  • Multi-tenant architecture with organization-scoped data
  • Automated Alembic migrations and role seeding on boot
  • Financial charge lifecycle with pending, paid and overdue states
  • Auto-settlement algorithm that matches payments against oldest outstanding charges
  • SendGrid email integration for password reset flows
  • Audit logging service for operational traceability
