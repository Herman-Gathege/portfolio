EduLearn Platform

A full-stack education platform that allows users to discover courses, leave reviews, and manage learning progress through a secure and responsive web interface.

Role Fullstack Developer

Type Education Platform
Tools JWT · Postman · Bootstrap

Problem

Students often struggle to find well-organized platforms that allow them to browse courses, evaluate reviews, and manage learning content in a single unified environment.

Solution

EduLearn provides a structured platform where users can explore courses, leave reviews, and securely manage their accounts while discovering educational content tailored to their interests.

Key Features

  • Secure JWT authentication system
  • Course discovery with search and filtering
  • User reviews and ratings
  • Responsive course browsing interface
  • Dynamic course listings powered by APIs

Implementation

  • React frontend with Bootstrap UI components
  • Flask backend REST API
  • PostgreSQL database for structured course data
  • Postman used for API testing and validation
  • Optimized UI for desktop and mobile users
